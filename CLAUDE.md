# CLAUDE.md

## Project

Personal portfolio site for Leo Succar (leo.dev). Stack:

- **TanStack Start** (React 19) — file-based routes in `src/routes/`, server-rendered on a **Cloudflare Worker** via `@cloudflare/vite-plugin`; TypeScript strict mode
- **Tailwind CSS 4** — configured in `src/styles.css` (`@theme`), no `tailwind.config.js`; shadcn-style `src/components/ui/` primitives on **Base UI**
- **Content in Cloudflare D1** (Drizzle ORM), **images in R2**, edited at **`/admin`** (a small built-in CMS behind Cloudflare Access). Sanity was removed on 2026-11-09
- **motion** (`motion/react`) — animations
- **pnpm**, exact-pinned versions. Nothing from Vercel (no Next.js, no `vercel` CLI, no `next-*` packages); keep it that way.

## Layout

- `src/server.ts` — Worker entry: `/images/*` from R2 (edge-cached, immutable), the `/resume` → `/resume.html` rewrite, the Access check for `/admin` pages, then TanStack Start's handler
- `src/router.tsx`, `src/client.tsx` — router and hydration entry
- `src/routes/__root.tsx` — HTML shell, meta tags, theme script, 404 page
- `src/routes/_site/index.tsx` — the home page at `/`. `/projects` (`projects.index.tsx`) renders the same page with a canonical link to `/`, and deliberately does not redirect: the old site sent `/` to `/projects` with a cached 308, so a redirect back would loop
- `src/routes/_site/` — the site's pages under a pathless `_site` layout: `projects.index.tsx`, `projects.$slug.tsx` (404 for unknown slugs), `life-calendar.tsx`, `soon.tsx`
- `src/server/content.ts` — server functions the public pages read D1 through
- `src/server/db/` — Drizzle schema (`schema.ts`) and the D1 handle; migrations in `drizzle/migrations/`, the one-off Sanity import in `drizzle/seed/`
- `src/server/admin.ts` — admin server functions (CRUD, reorder, image upload), each behind `requireAdmin` (`src/server/auth/`)
- `src/routes/admin*` — the admin UI; shared editors in `src/components/admin/`
- `src/components/`, `src/hooks/`, `src/lib/` (`theme.tsx` is the light/dark theme provider)

## Deployment and content freshness

- The site deploys as a Cloudflare Worker named `leodotdev` on the route `leo.dev/*` (`wrangler.jsonc`); ship with `pnpm run deploy`. Static files in `public/` are served before the Worker runs (`html_handling: "none"`, so `/resume.html` stays reachable as is).
- Pages render per request and read D1 directly, so **edits made at `/admin` show up on the next page load**, with no rebuild or deploy.
- `pnpm dev` uses the **production** D1 database and R2 bucket (`remote: true` in `wrangler.jsonc`), like mdc: local admin edits are live.
- Workers runtime only: no Node `fs`; `nodejs_compat` is on. Use `cloudflare:workers` for `env`/`waitUntil`.

## Conventions

- Path alias `@/*` → `src/*` (configured in `tsconfig.json`)
- Routes: `createFileRoute`, data in `loader` via server functions; internal links use TanStack `Link` (`to="/projects/$slug"` + `params`), external links and static files use plain `<a>`
- Images: stored as `Img` records (`src/lib/image.ts`): WebP at 320/960/1920px in R2, named `<base>-<width>.webp`. Render with plain `<img {...imageProps(img, { maxWidth })}>` and pass `sizes`. Plain strings (files in `public/`, like the experience logos) pass through. Admin uploads are resized in the browser (`src/lib/resize.ts`); SVG uploads are refused (same-origin script risk)
- Fonts: `@fontsource-variable/inter` (body) and `@fontsource-variable/playfair-display` (`font-playfair`), imported in `src/styles.css`
- Type scale: only `text-xs` (12px) and `text-base` (16px) exist; other `text-<size>` classes are no-ops
- Icons from `react-icons/tb` (Tabler icon set)
- Styling via Tailwind classes; utility helper `cn()` from `src/lib/utils.ts`

## Admin (`/admin`)

A small CMS for projects, experience and references (books are in D1 too, but the shelf is hidden and has no editor yet).

- **Auth:** a Cloudflare Access application for `leo.dev/admin*` (team `leodotdev.cloudflareaccess.com`) gates the pages at the edge. The Worker re-verifies the Access JWT for `/admin` pages (`src/server.ts`), and every admin server function verifies it again (`requireAdmin`), reading the `Cf-Access-Jwt-Assertion` header or, for `/_serverfn` calls outside the Access path, the `CF_Authorization` cookie. `ACCESS_AUD` in `wrangler.jsonc` must hold the application's audience tag; while it is empty, production refuses `/admin` and every admin call.
- **Local dev:** `vite dev` on localhost skips the Access check (`import.meta.env.DEV`, compiled out of production builds).
- **Writes** go straight to production D1/R2; there is no draft state. Deleting a project or image does not delete its files from R2 (they are cheap and keys are never reused).
