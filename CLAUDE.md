# CLAUDE.md

## Project

Personal portfolio site for Leo Succar (leo.dev). Stack:

- **TanStack Start** (React 19) — file-based routes in `src/routes/`, server-rendered on a **Cloudflare Worker** via `@cloudflare/vite-plugin`; TypeScript strict mode
- **Tailwind CSS 4** — configured in `src/styles.css` (`@theme`), no `tailwind.config.js`; shadcn-style `src/components/ui/` primitives on **Base UI**
- **Sanity CMS** — headless CMS; project `jyqe7nab`, dataset `production`
- **motion** (`motion/react`) — animations
- **pnpm**, exact-pinned versions. Nothing from Vercel (no Next.js, no `vercel` CLI, no `next-*` packages); keep it that way.

## Layout

- `src/server.ts` — Worker entry: the `/resume` → `/resume.html` rewrite, then TanStack Start's handler
- `src/router.tsx`, `src/client.tsx` — router and hydration entry
- `src/routes/__root.tsx` — HTML shell, meta tags, theme script, 404 page
- `src/routes/index.tsx` — `/` redirects (308) to `/projects`
- `src/routes/_site/` — the site's pages under a pathless `_site` layout: `projects.index.tsx`, `projects.$slug.tsx` (404 for unknown slugs), `life-calendar.tsx`, `soon.tsx`
- `src/server/content.ts` — server functions that read Sanity; `src/server/cache.ts` — stale-while-revalidate on the Workers Cache API
- `src/sanity/` — project config, GROQ (`queries.ts`), image URLs (`image.ts`), browser write client
- `src/components/`, `src/hooks/`, `src/lib/` (`theme.tsx` is the light/dark theme provider)
- `studio/` — Sanity Studio and the content schemas, a separate package with its own install (the Sanity CLI pulls in Vercel packages, so it stays out of the site's dependencies)

## Deployment and content freshness

- The site deploys as a Cloudflare Worker named `leodotdev` on the route `leo.dev/*` (`wrangler.jsonc`); ship with `pnpm run deploy`. Static files in `public/` are served before the Worker runs (`html_handling: "none"`, so `/resume.html` stays reachable as is).
- Pages render per request. Sanity reads go through `src/server/content.ts` and are cached at the edge for 60 s fresh plus a day stale-while-revalidate, so **content edits appear within about a minute with no rebuild**. No deploy hook or webhook is needed.
- Do **not** add a `/studio` route; run the Studio locally (`pnpm studio`) or use sanity.io/manage.
- Workers runtime only: no Node `fs`; `nodejs_compat` is on. Use `cloudflare:workers` for `env`/`waitUntil`.

## Conventions

- Path alias `@/*` → `src/*` (configured in `tsconfig.json`)
- Routes: `createFileRoute`, data in `loader` via server functions; internal links use TanStack `Link` (`to="/projects/$slug"` + `params`), external links and static files use plain `<a>`
- Images: plain `<img>` with `sanityImageProps()` from `src/sanity/image.ts` for `src`/`srcSet` (Sanity's image CDN does the resizing); pass `sizes`
- Fonts: `@fontsource-variable/inter` (body) and `@fontsource-variable/playfair-display` (`font-playfair`), imported in `src/styles.css`
- Type scale: only `text-xs` (12px) and `text-base` (16px) exist; other `text-<size>` classes are no-ops
- Icons from `react-icons/tb` (Tabler icon set)
- Styling via Tailwind classes; utility helper `cn()` from `src/lib/utils.ts`

## Content: experience and references

Experience and reference entries live in Sanity (types `experience` and `reference`, ordered by `order asc`). Edit them at sanity.io/manage; changes appear on the site within about a minute.

## Inline description editing

Project descriptions on the `/projects` list (the projects section is currently hidden) are editable in-place by Sanity project members. The mechanism uses cookie-credentialed Sanity mutations via `src/sanity/write-client.ts` (no token in the bundle). The `src/hooks/useSanityAdmin.ts` hook detects admin status by calling `/users/me` with credentials; non-members get a read-only view. Double-clicking a description (or its "Description coming soon." placeholder) opens an inline textarea; `Cmd/Ctrl+Enter` or blur saves, `Escape` cancels.

**Prerequisites (operator's responsibility):**
- Sanity CORS origins must have credentials enabled: add `http://localhost:3000` and `https://leo.dev` at sanity.io/manage → API → CORS origins → "Allow credentials".
- Edits publish immediately (no draft workflow) and appear to visitors within about a minute.
