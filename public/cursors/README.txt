The demo cursor's pictures on leo.dev/work/claude: arrow.svg, pointer.svg,
text.svg, and ew-resize.svg.

They are the "default", "pointinghand", "ibeam", and "resizeleftright"
cursors from the Figma Community file "Vector macOS cursors", whose layers
credit the Azendoo design team (@azendoo). Each was exported from the file as
SVG at its own size; the only change is that the page background the export
draws behind a cursor was removed.

Figma Community files are shared under CC BY 4.0 unless their page says
otherwise.

Until 2026-11-19 this folder held macOS-style cursors from the apple_cursor
project (GPL-3.0), which these replace.
